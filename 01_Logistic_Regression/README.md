# Logistic Regression with NumPy

## Overview
Implementation of Logistic Regression using NumPy without machine learning training frameworks.

## Dataset
- Wisconsin Breast Cancer Dataset
- 569 samples, 30 features
- Binary classification: Malignant / Benign
- Train/Test split: 80/20

## Implementation
- Sigmoid activation
- Binary Cross Entropy Loss
- Backpropagation
- Gradient Descent
- Feature Standardization
- Model Evaluation

## Training Configuration
- Learning Rate: 0.1
- Epochs: 2000

## Results

| Metric | Score |
|---|---:|
| Train Accuracy | 98.90% |
| Test Accuracy | 97.37% |
| Precision | 95.35% |
| Recall | 97.62% |
| F1-score | 96.47% |

## Key Takeaways
Implemented and trained a binary classification model from scratch using NumPy. Evaluated generalization performance on unseen test data and analyzed classification errors using precision, recall, and F1-score.

*This project is for machine learning education, not clinical diagnosis.*
